Ladakh ESP32 Weather Station & $\text{PM}_{2.5}$ ForecastingOverviewThis project combines a custom-built ESP32 multi-sensor hardware weather station in Ladakh with gradient-boosted regression models to forecast atmospheric $\text{PM}_{2.5}$ concentrations. Environmental telemetry is logged locally and used to train and evaluate forecasting models across multiple prediction horizons.Sample Data LogA sample overnight data log collected directly from the weather station is attached for reference, showing real sensor readings captured across an overnight run. (Make sure any public log file only contains shareable telemetry and excludes restricted or sensitive metadata.)Modeling & Key ObservationsBaseline vs. Optuna Optimization: An initial, unoptimized XGBoost model was trained first as a baseline, followed by hyperparameter tuning with Optuna, which reduced the Mean Absolute Error (MAE) down to 5.32–5.89.Prediction Horizon Trend: During training, prediction error/loss consistently decreased as the forecast horizon lengthened—meaning short-term 1-minute forecasts exhibited higher loss than longer-horizon 1-hour predictions due to high-frequency micro-fluctuations and sensor noise over short intervals.
